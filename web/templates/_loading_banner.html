{# 慢调用 loading 反馈 banner · 通用 macro 设计原则：用户点完按钮看到的反馈必须**比按钮本身的 disabled 视觉更醒目**—— 按钮变灰一秒钟用户就以为坏了。Banner 必须在按钮**附近**而非 topbar 角落。 参数： - cond: x-if 条件表达式（如 "$store.topic.loading"） - label: 主文案（如 "DeepSeek 正在生成 6 条候选"） - elapsed: elapsedSec 表达式（如 "$store.topic.elapsedSec"） - est: 进度条 cap 秒数（按估算总时长，进度满格） - note: 副文案（如 "通常 25-40 秒"） 配套 store 字段：elapsedSec: 0, _tickHandle: null 配套 generate 函数： this.elapsedSec = 0; this._tickHandle = setInterval(() => { this.elapsedSec = Math.round((Date.now()-t0)/1000); }, 500); finally: clearInterval(this._tickHandle); this._tickHandle = null; #} {% macro loading_banner(cond, label, elapsed, est=30, note='') %} {% endmacro %}
